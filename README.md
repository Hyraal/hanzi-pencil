# Hanzi Pencil

Web app per iPad per esercitarsi nella scrittura dei 600 caratteri HSK 1-2 e di 862 parole HSK 1-2 (es. 准备) con la Apple Pencil.

`data/words.json` si rigenera con `python3 tools/build_words.py` dal mazzo Anki `~/Desktop/Cinese/HSK_1264_vocaboli_Anki.txt`.
Ordine dei tratti e dati: [Hanzi Writer](https://hanziwriter.org) (MIT) e Make Me a Hanzi.
